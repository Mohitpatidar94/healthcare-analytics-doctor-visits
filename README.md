# Healthcare Analytics for Doctor Visits

## Overview
This project performs data analysis and visualization on a healthcare dataset to understand patterns in doctor visits. It explores various patient demographic factors, health conditions, and insurance types to uncover insights into healthcare utilization. This project was developed as part of the Vodafone Idea Foundation internship.

## Dataset
The dataset used in this project (`1776250375-P2-Healthcare Analytics for Doctor Visits (1).csv`) contains the following key features:
- `visits`: Number of doctor visits
- `gender`: Patient's gender
- `age`: Patient's age
- `income`: Patient's income
- `illness`: Number of illnesses
- `reduced`: Number of days of reduced activity
- `health`: General health status
- `private`: Has private health insurance?
- `freepoor`: Has free government health insurance due to low income?
- `freerepat`: Has free government health insurance due to age/disability/veteran status?
- `nchronic`: Condition status (chronic)
- `lchronic`: Condition status (long-term chronic)

## Requirements
The following Python libraries are required to run the Jupyter Notebook:
- pandas
- numpy
- matplotlib
- seaborn
- jupyter

## Installation and Usage
1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd "Voice Project 2 Analysis"
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Open `Healthcare_Analytics_for_Doctor_Visits_.ipynb` to view the analysis.
